1. CONFIGURING THE LLM (config.toml)
--------------------------------------------------------------------------------
The project uses litellm under the hood, so Claude models are supported.
Edit API-Based-Agent/config.toml:

    [llm]
    model="anthropic/claude-sonnet-4-6"
    api_key="sk-ant-..."
    base_url=""
    embedding_model="openai"

Model name format follows litellm: anthropic/claude-sonnet-4-6, anthropic/claude-opus-4-8, etc.
Leave base_url empty when using Anthropic directly (remove the CMU litellm proxy URL).
Your api_key should be your Anthropic key (starts with sk-ant-).

Available Claude models:
  - claude-opus-4-8   (most capable)
  - claude-sonnet-4-6 (balanced)
  - claude-haiku-4-5  (fastest)

3. RUNNING THE EVALUATION (run_infer.sh)
--------------------------------------------------------------------------------
Script location: evaluation/webarena/scripts/run_infer.sh
Run from: API-Based-Agent/ directory

What it does:
  - Runs the CodeActAgent on WebArena tasks using your configured LLM
  - Saves results to: evaluation/evaluation_outputs/outputs/webarena/...
      logs/instance_<task_id>.log  — per-task agent trajectory
      metadata.json                — run config
      output_<model>.jsonl         — one JSON line per task with results

Key flags:
  --start_task_id     Which task to start from (determines which site runs)
  --eval-n-limit      Max number of tasks to run (remove for all tasks in site)
  --max-iterations    Max turns the agent gets per task (default: 18)
  --eval-num-workers  Parallel workers (keep at 1 unless you have resources)

The model is read from config.toml via --llm-config llm.

TO SKIP MAP AND WIKIPEDIA — run the script once per site you want:

    for START_ID in 0 21 27 44 552 671; do
      poetry run python evaluation/webarena/run_infer.py \
        --agent-cls CodeActAgent \
        --llm-config llm \
        --start_task_id $START_ID \
        --max-iterations 18 \
        --eval-num-workers 1 \
        --eval-note <your_note>
    done

4. HOW THE CODEACT AGENT WORKS
--------------------------------------------------------------------------------
The agent is in: agenthub/codeact_agent/codeact_agent.py
The abstract base class is in: opendevin/controller/agent.py (interface only)

This is a CodeAct agent, NOT pure ReAct:
  - ReAct:    explicit Thought → Action → Observation cycle (labeled steps)
  - CodeAct:  LLM outputs code directly; reasoning is implicit in free text
              before the code block. Framework only parses the code tags.

The step() method is called ONCE per turn by the OpenDevin controller.
Each call rebuilds the full message history from state.history and calls
the LLM to get the next action. The controller handles the outer loop.

Action types the agent can take:
  <execute_bash>    — run a bash command
  <execute_ipython> — run Python in an IPython kernel
  <execute_browse>  — interact with the browser

IMPORTANT: The first 3 turns per task are hardcoded login sequences
(navigate to site, fill credentials, click login). The LLM is NOT called
for these turns. Actual agent reasoning starts at turn 4.

7. MULTI-DOCKER PARALLEL EVALUATION (--multi-docker)
--------------------------------------------------------------------------------
Tasks can now run in parallel across multiple isolated Docker workers managed
by the SSH orchestrator at /scr2/webagent-verified/webarena_orchestrator/.

NEW FILES:
  evaluation/webarena/worker_pool/__init__.py  — package init
  evaluation/webarena/worker_pool/workers.py   — SSH worker pool client

HOW IT WORKS:
  Each task acquires its own docker worker over SSH (separate GitLab/Shopping/
  Reddit instance on a different port). The agent runs in a ProcessPoolExecutor
  subprocess so GITLAB/SHOPPING/REDDIT env vars can be set per-task without
  interfering with other concurrent tasks.

REQUIREMENTS:
  - REMOTE_HOST env var must point to the orchestrator server
      export REMOTE_HOST=annabella@red5k.cs.berkeley.edu
  - SSH key-based auth to that host (no password prompt)
  - The orchestrator script must be accessible at:
      /scr2/webagent-verified/webarena_orchestrator/orchestrator.py

USAGE:
  export REMOTE_HOST=annabella@red5k.cs.berkeley.edu
  poetry run python evaluation/webarena/run_infer.py \
    --agent-cls CodeActAgent \
    --llm-config llm \
    --start_task_id 44 \
    --max-iterations 18 \
    --multi-docker

NOTES:
  - Parallelism is capped at num_workers() (how many docker workers the
    orchestrator reports as available).
  - map and wikipedia tasks don't use a docker worker — they still work but
    will use whatever MAP/WIKIPEDIA env vars are set in .env.
  - Without --multi-docker the original sequential path is unchanged.
